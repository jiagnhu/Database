# CPV 企业知识库设计

用户目标：将已有中英对照学习资料升级为中国大陆使用的私有知识库，使用阿里云百炼，回答可回到原文。用户最新明确：仅本人使用，未来不作为收费项目。按可靠、可维护的单用户系统交付，不做订阅、收费或团队管理界面。现有离线 HTML 保留。以下未明确的细节为实施选择。

## 方案与边界

采用 Next.js/TypeScript 单体应用 + Supabase PostgreSQL/Auth/Storage + Python 后台处理器。与全托管百炼知识库相比，自建检索可保持已有句子 ID、版本和权限；与多微服务相比，模块化单体更易维护和控制成本。服务器部署地点与现有 Supabase 项目待用户提供，不修改已有两个欧洲区项目。国内百炼默认北京端点，可配置业务空间专属域名。

交付本地可运行项目、真实语料预览、数据库迁移、后台入库、容器和运维文档。没有目标项目凭据时，不声称完成云端接入或生产上线。生产不得启用预览数据或绕过登录。企业上线仍需在目标环境完成真实模型/邮件/存储验证与备份恢复演练。

## 访问模型

私有空间为安全边界；仅配置的本人账号具有 admin 权限。底层 membership/RLS 保留作为安全机制，不开放邀请或用户管理。按用户后续要求，Supabase 保留公开注册和邮箱确认；当前网页尚无自助注册表单。注册与资料授权分开，所有检索、原文、聊天和存储访问受空间成员状态约束。暂不实现团队、部门、SSO、付费、订阅或跨企业共享。

采用数据库 RLS 和服务端身份验证双重检查。角色来自成员表，不能来自可编辑的用户元数据。服务密钥仅限成员邀请和后台任务。组织 ID 不信任客户端，服务端确认成员后使用。用户停用立即阻断后续数据操作。

## 内容与回答

复用 9 份现有文件、2,509 个对照片段，保留原始来源、页/段落、句子 ID。原始资料是证据，不是系统指令。新文档独立版本导入，不覆盖历史原文；PDF/DOCX/PPTX 提取后生成翻译和 1024 维向量，进入待审核，编辑发布后才参与普通成员检索。扫描 PDF 支持 OCR；复杂版面需审核，不能保证自动提取完全准确。

关键词（含中文分词近似）与向量混合检索，每次最多取 6 个片段，限制上下文长度。生成 JSON 段落与引用 ID；应用检查引用属于本次检索结果，缺依据时拒答。引用校验不能证明语义完全正确，保留原文供核对。选句提问把所选句作为证据，仅服务端读取原文。回答不自动联网补充法规。

## 成本与可靠性

默认 qwen-plus 非思考问答、qwen-flash 翻译、text-embedding-v4 1024 维；全部可配置，变更向量模型需重建索引。问答输出最多 1200 token；最多保留 4 条短历史；不自动多模型评审或无限重试。向量内容哈希去重，组织级每日额度采用数据库原子预留，失败且费用未知时保留预留。接口限流、请求超时、幂等 ID、后台租约和有限重试。

日志仅记录请求 ID、动作、状态和计量；不记录密钥、完整文档或问题正文。上传限制大小、格式和解压体积，后台病毒扫描失败时不处理。文件保存在私有桶，原文件下载逐次鉴权。部署提供非 root 容器、健康检查、环境校验和备份/回滚说明。

## 验证范围

一次类型检查和生产构建；有针对性的引用/限额/输入验证测试；真实 PostgreSQL 中验证跨组织与停用访问、角色修改和配额并发；一轮桌面/移动 UI 核心流程。未获得凭据前使用模拟的模型传输边界，不调用收费模型，不进行无目标压力测试。
